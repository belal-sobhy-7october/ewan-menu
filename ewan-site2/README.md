# Brocele Cafe & Eatery — Free Bootstrap 5 Homepage

The **free version** of the Brocele Cafe & Eatery template — a single, complete homepage built with Bootstrap 5. No build step, no dependencies to install — open `index.html` and go.

Want the full 9-page template (Menu, About, Gallery, Team, Blog, Style Guide, Contact + a working PHP contact form)? See [`../brocele/README.md`](../brocele/README.md).

---

## What's included

- `index.html` — the complete homepage: hero, drink carousel, process steps, "What We Offer", reservation photo grid, testimonials, menu preview, book-a-table form, gallery preview (with a working lightbox), partner logos and newsletter signup
- `assets/` — all CSS, JS and image assets needed to run the page

## What's different from the full version

This is a homepage-only package, so a few things are intentionally simplified:

- The **Pages** dropdown in the header lists the same additional pages as the full template, but they're shown disabled and tagged `PRO` — those pages simply aren't part of this free package.
- "Menu", "View Menu" and "Book a Table" links scroll to the relevant section on this same page instead of linking to separate pages.
- The gallery preview images open in an on-page lightbox rather than linking to a dedicated gallery page.
- The reservation form is a front-end demo only (no backend) — the full version ships with a working PHP contact form.

## Getting started

Just open `index.html` in a browser — that's it, no server required.

## Customizing

All colors, fonts and spacing are defined as CSS variables at the top of `assets/css/style.css` (`:root { --brown: ...; --tan: ...; }`) — change them once and they apply across the whole page.
